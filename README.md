# Emotion Detection Web Application

## Project Overview

This project implements an AI-based Emotion Detection application using the Watson NLP library.

The application analyzes a given text and detects five emotions:

- Anger
- Disgust
- Fear
- Joy
- Sadness

It also identifies the dominant emotion expressed in the input text.

## Technologies Used

- Python
- Watson NLP
- Flask
- Requests
- unittest
- Pylint
